# RTEMS Real-Time Systems — Academic Reports

This directory contains two technical reports completed
as part of the Master's course Vertiefung Echtzeitsysteme
at Berliner Hochschule für Technik (BHT) in 2026.

## Laboratory 2 — Thread Scheduling and Analysis

[RTEMS Thread Scheduling & Analysis Report](RTEMS_Thread_Scheduling_Analysis_Report.pdf)

A 15-page technical investigation covering:

- POSIX thread scheduling under RTEMS
- Thread states and synchronisation
- GDB debugging with QEMU
- RTEMS Capture Engine
- Priority inversion and priority inheritance
- Execution traces and scheduling diagrams

## Laboratory 3 — GPIO Embedded Control

[RTEMS GPIO Embedded Control Report](RTEMS_GPIO_Embedded_Control_Report.pdf)

A 13-page technical report documenting:

- C programming with RTEMS
- Raspberry Pi GPIO integration
- POSIX real-time threads
- Interrupt handling
- Mutex and semaphore synchronisation
- Runtime configuration
- Hardware testing and experimental results
